# Expense Tracker

A small HTML, CSS, and JavaScript training project for practicing GitHub collaboration.

## Branch workflow

```text
main
  ↓
development
  ↓
feature branches
```

- `main` keeps the stable approved source.
- `development` combines completed team work for testing.
- `feature/...` branches hold one teammate's task at a time.

## Feature branches

- `feature/ui`
- `feature/add-expense`
- `feature/storage`
- `feature/filter`

## Run locally

Open `index.html` in a browser.
